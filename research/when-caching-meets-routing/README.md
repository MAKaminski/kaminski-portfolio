# When Caching Meets Routing

A cache-aware cost model for selective frontier-model routing in multi-turn voice agents.
Michael Kaminski, technical white paper, 2026-09-28. Preprint, not peer-reviewed.

Published at https://www.michael-kaminski.io/papers
(PDF: `/docs/papers/when-caching-meets-routing.pdf`).

## Rerun it

```sh
pip install numpy scipy matplotlib
python3 model.py     # ~10 s: writes results.json and figures/*.pdf
python3 macros.py    # writes every number quoted in the text into numbers.tex
pdflatex paper.tex && pdflatex paper.tex
```

All seeds are fixed, so a rerun reproduces `numbers.tex` byte for byte.

## Inputs

- Prices: Anthropic list prices and prompt-caching rules, retrieved 2026-09-28
  (`PRICES` in `model.py`, Table 1 in the paper).
- Workload: stated assumptions for a contact-center voice agent (`BASE` in `model.py`,
  Table 2). None of it is measured from a deployment; replace it with your own traces.

## Revision notes (2026-09-29, before publication)

- Sticky escalation no longer pays for a router call on turns after the conversation has
  escalated. It had been charging the classifier on every turn, which understated the
  policy by about 2.4 points: Haiku −2.6% → −0.2%, Sonnet −12.9% → −10.4%. No other
  number changed.
- The no-hard-turn share (now 18.4%, analytic), the conversation-routing ceiling (12.9%)
  and the validation gap (1.1 points) are generated by the scripts instead of typed into
  the text.
- The validation is described as what it is: a check of the list-price and escalation
  arithmetic with caching off, not of the cache-billing path. A limitation notes that the
  cache path has not been reconciled against real invoices.
- Per-model cache isolation is stated as following from identical-prefix matching and
  model-specific cached state; the cited documentation does not say it in those words.
